# Site Quem Sou Eu

Site simples desenvolvido com HTML, CSS e JavaScript.

## Arquivos
- `index.html`: textos e estrutura do site.
- `style.css`: cores e aparência.
- `script.js`: função do botão "Voltar ao topo".

## Personalização
Abra o arquivo `index.html` e altere os textos para colocar suas próprias informações.
